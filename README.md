# 香江渡輪 · v0.1

碼頭售票員遊戲原型。1980 年代，中環往尖沙咀天星小輪。

一更 3 分鐘 = 07:00–09:00。賣飛、收錢、找續。開船前 10 秒截龍，上唔到船嘅客會走。

---

## 點樣玩

**最簡單：雙擊 `index.html`。**

因為冇 build step、冇 module、冇 fetch，直接用瀏覽器開就得。

如果你想用手機試，或者想有個本機網址：

```sh
node test/server.js
# 開 http://127.0.0.1:5173
```

手機要同電腦同一個 Wi-Fi，然後開 `http://<你部電腦嘅 IP>:5173`。

---

## 玩法

1. 客行到窗口，對話泡會講要幾多張飛（例如「兩張成人，一張小童」）
2. 撳下面嘅票種，撳幾多次就係幾多張
3. 撳「收錢」—— 客人會俾一張銀紙，你要計返找續
4. 撳硬幣掣砌出找續金額，撳「找續 ✓」
5. 開船前 10 秒截龍，龍入面嘅人會上唔到船

**找續 = 收到 － 小計**

### 鍵盤（電腦快好多）

| 掣 | 作用 |
|---|---|
| `1` `2` `3` | 成人 / 小童 / 長者 |
| `Enter` | 收錢，或者找續確認 |
| `Backspace` | 清單，或者重設找續 |

## 數值喺邊度改

全部喺 **`js/rules.js`** 開頭：

```js
const CFG = {
  shiftSec: 180,       // 一更幾秒
  boatSec: 45,         // 一班船隔幾耐
  cutoffBefore: 10,    // 開船前幾秒截龍
  minCust: 8,          // 每班船最少幾多客
  maxCust: 11,         // 每班船最多幾多客
  queueMax: 8,         // 龍最多幾多人
};

const FARES = { adult: 150, child: 80, senior: 50 };  // 單位：仙
```

改完 refresh 就見到，唔使 build。

### 想加一種票？

1. `FARES` 加一項，例如 `student: 100`
2. `LABEL` 加 `student: '學生'`
3. `TYPES` 陣列加 `'student'`
4. `index.html` 加一粒掣（複製 `.ticket` 嗰段）
5. `makeWant()` 加機會率

## 自動測試

唔開瀏覽器都測到規則有冇爆：

```sh
node test/sim.js
```

佢會用「完美玩家」同「求其玩家」各玩三更，檢查：
- 完美玩家零失誤
- 求其玩家一定出錯（證明錯誤偵測有效）
- 兩個都玩到收工

改完數值跑一次，好快就知有冇搞爛。

## 已知限制（v0.1 刻意留白）

- 冇八達通（1990 年代才有）
- 冇航線選擇（得一條）
- 冇存檔
- 冇音效
- 冇「漏收錢」失誤

詳細設計見 **`docs/GAME.md`**。
