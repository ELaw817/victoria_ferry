# 維多利亞小輪 · v0.2.1

碼頭售票員遊戲原型。中環往尖沙咀小輪，兩個年代：1980 現金找續、1990 八達通 + 貨票。

一更 3 分鐘 = 07:00–09:00。賣飛、收錢、找續／拍卡、收貨票、查核年齡。開船前 10 秒截龍，上唔到船嘅客會走。

---

## 點樣玩

**最簡單：雙擊 `index.html`。**

因為冇 build step、冇 module、冇 fetch，直接用瀏覽器開就得。

如果你想用手機試，或者想有個本機網址：

```sh
node test/server.js
# 開 http://127.0.0.1:5173
```

手機要同電腦同一個 Wi-Fi，然後開 `http://<你部電腦嘅 IP>:5173`。

## 玩法

1. 開場揀年代：**一九八〇**（硬幣）或者 **一九九〇**（八達通 + 貨票）
2. 客行到窗口，對話泡會講要幾多張飛（例如「兩張成人，一張小童」）
3. 撳下面嘅票種，撳幾多次就係幾多張
4. 撳「收錢」：
   - **現金客**：人票 + 貨票一筆過，撳硬幣砌返找續 → 「找續 ✓」
     - 客人俾啱啱好？撳「唔使找」（`0`）就得
   - **八達通客**：先拍卡俾人票；有貨就再收貨票現金
5. 有貨嘅客（1990）：行到窗口才見到，畫面會顯示「貨：電視、木梯×2」
   → 撳返對應嘅貨票（**只收現金**）
6. 「細路」生晒鬍鬚？撳「查核年齡」（`Q`）：
   - 真係大人 → 自動轉成人票
   - 真係細路 → 客人唔高興（心情 −20）
   - 唔查又照賣小童票 → 主任扣分
7. 開船前 10 秒截龍，龍入面嘅人會上唔到船

**找續 = 收到 － 小計**

> 貨票出錯或者找錯錢，後面成條龍每個客心情 −30；心情跌到 0 嗰個會走。

### 鍵盤（電腦快好多）

| 掣 | 作用 |
|---|---|
| `1` `2` `3` | 成人 / 小童 / 長者 |
| `Q` | 查核年齡 |
| `0` | 啱啱好，唔使找 |
| `Enter` | 收錢 / 找續確認 / 拍卡 |
| `Backspace` | 清單，或者重設找續 |

## 數值喺邊度改

全部喺 **`js/rules.js`** 開頭：

```js
const CFG = {
  shiftSec: 180,          // 一更幾秒
  boatSec: 45,            // 一班船隔幾耐
  cutoffBefore: 10,       // 開船前幾秒截龍
  queueMoodHit: 30,       // 貨票／找錯錢：後面每個客心情 −30
  fakeChildChance: 0.22,  // 幾大機會有人扮小童
  ageMoodHit: 20,         // 查核客人：心情 −20
};

const ERAS = {
  '1980': { minCust: 8,  maxCust: 11, queueMax: 8,  octopus: 0,    cargoChance: 0,    ... },
  '1990': { minCust: 13, maxCust: 18, queueMax: 10, octopus: 0.65, cargoChance: 0.32, ... },
};

const FARES = { adult: 150, child: 80, senior: 50 };   // 單位：仙

const CARGO = {
  tv:     { label: '電視',   cent: 1200 },
  fridge: { label: '雪櫃',   cent: 1500 },
  bike:   { label: '單車',   cent: 800 },
  fan:    { label: '風扇',   cent: 600 },
  cooker: { label: '電飯煲', cent: 500 },
  ladder: { label: '木梯',   cent: 400 },
};
```

改完 refresh 就見到，唔使 build。

### 想加一種貨？

1. `CARGO` 加一項，例如 `radio: { label: '收音機', cent: 300 }`
2. `index.html` 加一粒 `.cargo` 掣（`data-cargo="radio"`）

`cargoChance` 控制幾多成客帶貨；`makeCargo()` 會自己抽。

### 想加一個年代？

1. `ERAS` 加一個 key，例如 `'2000'`（可以複製 1990 嗰舊再改）
2. `ERA_KEYS` 加 `'2000'`
3. `index.html` 加一粒 `.era` 掣
4. 想換色的話，`css/style.css` 加 `body[data-era="2000"]` 一組變數

`game.js` 同 `ui.js` 唔使改。

### 想加一種票？

1. `FARES` 加一項，例如 `student: 100`
2. `LABEL` 加 `student: '學生'`
3. `TYPES` 陣列加 `'student'`
4. `index.html` 加一粒掣（複製 `.ticket` 嗰段）
5. `makeWant()` 加機會率

## 自動測試

唔開瀏覽器都測到規則有冇爆：

```sh
node test/sim.js
```

佢會用「完美玩家」同「求其玩家」各玩三更 × 兩個年代，再直接砌客測試：

- 完美玩家零失誤；求其玩家一定出錯
- 1980 年代冇八達通、冇貨票
- 1990 人票八達通 + 貨票現金（兩段付款、總數正確）
- 漏貨票／找錯錢 → 後面每個客心情 −30
- 龍尾心情跌到 0 → 走人、計「上唔到船」
- 查核：扮小童、真小童、自動轉成人票
- 唔查核就照賣 → 記「查核漏招」

## 已知限制

- 1990 年代票價同 1980 一樣（刻意，只想證明工具變化）
- 貨票只喺 1990 年代有
- 查核只係問年齡，冇身份證／對白分支
- 冇航線選擇（得一條）
- 冇存檔
- 冇音效
- 未做閘位（v0.3）

詳細設計見 **`docs/GAME.md`**。
