### v0.2.1（改名 + 貨票 + 查核）

- **改名：維多利亞小輪**
- **貨票（1990 限定，只收現金）**
  - 貨種：電視 $12、雪櫃 $15、單車 $8、風扇 $6、電飯煲 $5、木梯 $4
  - 客人唔會早講；行到窗口，畫面出現「貨：…」提示
  - 八達通客：先拍人票，再收貨票現金（兩段付款）
  - 現金客：人票 + 貨票一筆過，找續照計
  - 龍上限：10 人
- **查核年齡**
  - 有細路嘅客，22% 有一個係成人扮小童（提示：生晒鬍鬚）
  - 撳「查核年齡」（鍵盤 `Q`）：查到成人即刻轉成人票；查到真小童，客人心情 −20
  - 唔查核就照賣小童票 → 記「查核漏招」，扣評級
- **龍嘅怨氣**
  - 貨票出錯／找錯錢 → 龍入面每個客心情 −30
  - 心情跌到 0 嘅客即刻走，計「上唔到船」
  - 畫面顯示「後面：正常／唔耐煩／想走」
- 硬幣加 $10／$5／$2（有貨票之後找續會大額）
- 結算加「貨票出錯」「查核漏招」兩行
- 測試加：貨票、混合付款、怨氣、查核、走客

### 而家嘅 contract（v0.2.1）

## 點測

```powershell
node test/sim.js
```

會用「完美玩家」同「求其玩家」各玩三更 × 兩個年代，再直接砌客測：

- 零失誤、有失誤、玩到收工
- 1980 冇八達通、冇貨票
- 1990 人票八達通 + 貨票現金（兩段付款）
- 漏貨票／找錯錢 → 後面每個客心情 −30
- 龍尾心情跌到 0 → 走人
- 查核：扮小童、真小童、自動轉成人票
- 冇查核就照賣 → 查核漏招

改完數值跑一次，好快知有冇搞爛。
